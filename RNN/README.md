# RNN for IMDB Sentiment Analysis

This project implements a Recurrent Neural Network (RNN) for sentiment analysis using the IMDB movie reviews dataset. The model learns patterns from text data to classify movie reviews as either positive or negative.

## Project Workflow
- Load and preprocess the IMDB dataset
- Tokenize and pad text sequences
- Build the RNN model
- Train and validate the model
- Evaluate model performance
- Predict review sentiment

## Technologies Used
- Python
- NumPy
- TensorFlow
- Scikit-learn


## Objective
The objective of this project is to demonstrate how Recurrent Neural Networks (RNNs) can be used for natural language processing tasks by accurately classifying movie reviews into positive or negative sentiments.
