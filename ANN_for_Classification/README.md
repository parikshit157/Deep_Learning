# ANN for Classification

This project implements an Artificial Neural Network (ANN) for a multi-class classification task using the Date Fruit dataset. The model learns patterns from the input features and classifies date fruits into their respective categories with high accuracy.

## Project Workflow
- Data preprocessing
- Feature scaling
- Train-test split
- Building the ANN model
- Model training and evaluation
- Predicting date fruit classes

## Technologies Used
- Python
- NumPy
- Pandas
- Scikit-learn
- TensorFlow

## Objective
The objective of this project is to demonstrate how Artificial Neural Networks can be applied to solve a classification problem by accurately identifying different varieties of date fruits based on their characteristics.
